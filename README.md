# Microservicio Sakura Pago - Sakura Salón

## Descripción del proyecto
El microservicio de Pagos de Sakura permite gestionar los pagos de los servicios del salón de belleza, registrando las transacciones realizadas por los clientes y facilitando el control de los pagos, anticipos y estados de cada reserva
